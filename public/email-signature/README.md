# ZeroBlue Email Signature Logo

Use `zeroblue-logo.png` for email signatures. It is a transparent PNG sized at
300 x 75 pixels.

Recommended HTML:

```html
<img
  src="https://zerobluetech.com/email-signature/zeroblue-logo.png"
  alt="ZeroBlue Technology Solutions"
  width="300"
  height="75"
  style="display:block;border:0;outline:none;text-decoration:none;width:300px;height:75px;"
>
```

`zeroblue-logo@2x.png` is included as a 600 x 150 high-resolution source for
clients that support retina-sized signature images.
